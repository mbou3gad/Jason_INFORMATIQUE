Tutoriel détaillé : Comment installer Windows 11 proprement (Clean Install)

Suivez ce tutoriel interactif. Cochez chaque étape réalisée pour mesurer votre progression.

20% complété
Table des matières & navigation rapide
1. Préparation de la clé USB d'installation 2. Configuration du BIOS / UEFI & Sauvegarde 3. Démarrage sur la clé (Boot Menu) 4. Partitionnement propre et installation 5. Configuration initiale (OOBE) sans compte MS
1
Étape 1 : Préparation de la clé USB d'installation avec Rufus
Matériel requis : Clé USB 8 Go ou plus, Rufus portable, image ISO officielle Microsoft.

1. Téléchargez l'image ISO de Windows 11 depuis le site officiel de Microsoft ou lancez Rufus qui propose un téléchargement direct.
2. Branchez votre clé USB (attention : tout son contenu sera effacé).
3. Dans Rufus, sélectionnez le schéma de partition GPT et le système de destination UEFI (non-CSM).
4. Dans les options de personnalisation de Windows, vous pouvez cocher : « Supprimer l'exigence de 4 Go+ de RAM, Secure Boot et TPM 2.0 » et « Supprimer l'obligation de créer un compte Microsoft en ligne ».

# Commande PowerShell alternative pour vérifier l'intégrité du fichier ISO Get-FileHash -Path "C:\ISOs\Win11_French_x64.iso" -Algorithm SHA256
2
Étape 2 : Configuration du BIOS/UEFI & Sauvegarde préalable
Points clés : Disque dur externe pour sauvegardes, touche d'accès BIOS (F2, F12, Suppr).

1. Sauvegardez l'intégralité de vos documents personnels, favoris de navigateur et clés de licences sur un support externe ou cloud.
2. Redémarrez votre machine en appuyant frénétiquement sur la touche d'accès au BIOS (selon la marque : F2 pour Asus/Dell/Acer, F10 pour HP, Suppr pour MSI).
3. Activez le mode UEFI Boot et activez TPM / fTPM (Intel PTT ou AMD fTPM).

3
Étape 3 : Démarrage sur la clé USB (Boot Menu)
Raccourcis Boot Menu : F12 (Dell, Lenovo), F8 (Asus), F9 (HP), F11 (MSI).

1. Insérez la clé USB préparée sur un port USB direct (évitez les hubs non alimentés).
2. Allumez le PC et appuyez immédiatement sur la touche du menu de démarrage (Boot Menu).
3. Sélectionnez votre clé précédée de la mention UEFI : [Nom de la clé] et validez avec Entrée.
4. L'écran bleu d'installation de Windows apparaît après quelques secondes.

4
Étape 4 : Partitionnement propre et installation du système
Attention : Cette étape supprime les partitions existantes sur le lecteur cible.

1. Choisissez la langue : Français et format horaire : Français (Congo ou France).
2. Cliquez sur « Installer maintenant », puis « Je n'ai pas de clé de produit » si votre licence numérique est déjà liée à la carte mère.
3. Choisissez l'option « Personnalisé : installer uniquement Windows (avancé) ».
4. Supprimez les anciennes partitions système (Partition principale, Récupération, Système EFI, MSR) sur le disque principal (Lecteur 0) jusqu'à obtenir un seul « Espace non alloué sur le lecteur 0 ».
5. Cliquez sur « Suivant » sans créer de partition manuellement : le programme créera automatiquement la table GPT requise.

5
Étape 5 : Premier démarrage (OOBE) sans compte Microsoft obligatoire
Astuce professionnelle : Création d'un compte local indépendant et fluide.

Si vous souhaitez installer Windows 11 sans renseigner d'adresse Microsoft :
1. Sur l'écran demandant de vous connecter à Internet ou à un compte, appuyez sur Maj + F10 (ou Fn + Maj + F10 sur certains PC portables) pour ouvrir l'invite de commande.
2. Saisissez la commande ci-dessous et appuyez sur Entrée :

OOBE\BYPASSNRO

3. L'ordinateur redémarre l'assistant OOBE. Vous pouvez maintenant cliquer sur le lien : « Je n'ai pas Internet » puis « Continuer avec une installation limitée » pour créer un compte administrateur local sécurisé.
